
# 🗓️ Gestor de Tareas con Alertas (UAT Mante)

¡Hola! Este es mi primer proyecto como estudiante de **Ingeniería en Sistemas Computacionales (ISC)** en la Unidad Académica Multidisciplinaria Mante (UAT). 

El objetivo es crear una aplicación que me permita registrar mis tareas de la universidad con su fecha de entrega y me mande un aviso **dos días antes** para que no se me olvide hacerlas.
